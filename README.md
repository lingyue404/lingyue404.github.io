# Ling Yue - Academic Homepage

Personal academic website built with HTML, CSS, and vanilla JavaScript, hosted on [GitHub Pages](https://lingyue404.github.io/).

## Directory Structure

```text
.
├── index.html            # Page structure and metadata
├── data/
│   └── content.js        # Website content
├── assets/
│   ├── css/style.css     # Styles
│   ├── js/main.js        # Rendering and interactions
│   └── img/              # Images and icons
├── files/                # Downloadable resources
└── .nojekyll             # Disables Jekyll processing
```

## Local Preview

No build step or dependencies are required. From the repository root, run:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
